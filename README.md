# ai-job-portal
Full Stack AI job portal build with Python
Job seekers can search , apply in 1-click , and get AI-based

## ✨ Features
- 🔍 Search jobs by role, location, skills
- 📝 Apply in 1-click
- 🤖 AI-based job recommendations
- 📊 Track your applications
- 👤 User profile & resume

## 🛠️ Tech Stack
- Python
- Flask
- HTML, CSS, JavaScript
- AI / Machine Learning

## 🚀 How to Run
```bash
pip install Flask
python app.py
